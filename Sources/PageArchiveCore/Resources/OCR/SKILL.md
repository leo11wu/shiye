# 书页识别

## 逐字转写

以原图上可辨认的字形为准，逐字保留大小写、词间空格、标点、异体字、IPA、组合附标、上下标和连字符。罕见拼法与印刷错误照原样记录。局部图更清楚时，用局部图核定该处。辨认不清的字符写 `⟦?⟧`，在 `uncertainty` 里注明所在行或词，以及具体看不清的符号。

优先完整交回已辨认的文字，保留原文繁简、断行和重音。区分污迹、透印和可见文字。

## 版面与结构

先扫视整页，区分正文、页边小字、脚注、表格和图像。按自然段或逻辑条目分区。

- `blocks` 按阅读顺序排列。横排单栏从上到下。双栏先判断起读侧，以通栏标题、表格等划分段落带，同一段落带内读完整个起读栏，再读另一栏。分别用 `single_column`、`two_columns_ltr`、`two_columns_rtl` 或 `other` 表达布局。各区块标为 `left`、`right` 或 `full`。
- 正文标题用 `heading`。页眉 `header` 放在前面，页脚及页码 `footer` 放在最后，印刷页码另填 `printed_page_label`。页眉、页脚和全页共用的页底注标为 `full`。
- 脚注 `footnote` 放在正文后、页脚前。正文与脚注均保留印刷注标。脚注 `note_id` 和正文的 `note_refs` 使用同一个编号，例如 `¹` 和 `1.` 均对应 `1`。配对不明时保留原字形并写明疑点。
- 页首接上页或页尾句子明显未完时，标记 `starts_mid_paragraph` 或 `ends_mid_paragraph`。这两个标记只对应首尾的正文段落。转写当前页的可见片段，保留连字符。
- 表格使用一个 `table` 区块。记录空格、零值和真实合并格，行列从 0 开始，跨度从 1 开始。表框内跨列标题也作合并格。单元格坐标使用整页坐标，无法定位填 `null`。网格可辨时由 `cells` 记录文字，表格 `text` 留空。网格无法辨认时，把可见文字留在 `text`，以空 `cells` 和 `uncertainty` 标记。
- 图像使用 `figure` 及其位置，印刷图注另记。确实没有内容的页用 `blank: true` 和空 `blocks`。

重读时先以整页定位，再对照裁切核查漏行、误字、顺序和表格。以原图核实反馈，返回完整书页。完成条件是交回格式有效、可编辑、可按框检查的转写，保留人工核对所需的疑点。
