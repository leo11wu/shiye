# 书籍转换使用与验证审查

审查日期：2026-11-06。对象：拾页 0.1.1 的现存项目、历史验证文件与真实书籍样本。本文记录本次读取时的证据快照，不把正在修改或尚未执行的验证列为通过。审查未调用付费 OCR API，未上传书页，未改写原书和旧识别成果，也未记录密钥。

## 1. 主要发现

真实书籍已经成功导入 155 页，但只完成前 3 页识别，余下 152 页仍为 `imported`，不是 152 页识别失败。3 次识别后，日志留下 49 条手工排版操作记录，其中 41 条为字号调整。这说明现有使用流程在很小的样本上已经产生较多排版操作；它不能单独证明识别慢、准确率差或用户的全部操作意图。

旧 PDF 导入存在独立确认的缩放缺陷：一个约 369 × 569 pt 的页面被输出为约 1026 × 1581 px 的画布，但书页内容仍仅约 370 × 570 px，居中并留下大量白边。独立几何实验发现，此场景下 `getDrawingTransform` 的 `a = d = 1`，没有按 200 / 72 放大。内容比例与 72 / 200 一致。因此，源 PDF 的页面尺寸与导入 PNG 的有效分辨率不能混为一谈；图像预处理必须先修正，才适合比较 OCR 引擎。

历史“验证通过”主要覆盖程序行为、合成文字排版与导入，不等同于真实书籍 OCR 准确率通过。现存人工金标准仍为空；未发现整本识别、整本完成时间或整本峰值内存的有效验收记录。

## 5. 最小验收标准与本次边界

先验证输入几何，再验证转换可用性，最后评估识别精度。

1. **输入几何：**非零 CropBox、90°/270° 页面、长边 4200 px 限制都正确；四角标记应位于对应角部，不能仅检查画布尺寸。真实第 6、20 页应与源 PDF 页面在内容占比、方向和边缘裁切上相符。
2. **整本工作流：**155 页页序完整；取消后能够续做；失败页可定位和重试；未处理页不能被当作空白页；原书与旧成果保留。任何整本耗时和内存数字都应来自完整运行，并注明硬件、页面数量、处理方式和测量范围。
3. **电子版可用性：**打开输出、搜索、复制和选中文本，验证可见书页与文字位置一致；检查段落、双栏、表格和脚注的复制顺序。若目标是保留原貌的可搜索 PDF，优先完成这一链路，再评估重排是否值得增加人工操作。
4. **准确率：**[人工核对.md](人工核对.md) 要求独立人工建立至少 5,000 个正文字元和 200 次特殊字符出现的金标准；原始 CER ≤ 2%，特殊字符错误为 0，覆盖完整并检查连续 5 页。未识别区域不能从分母中消失；不能用同一识别结果或另一模型生成“金标准”。
5. **统计脚本边界：**`scripts/audit_cer.py` 只做 NFC 与空白归一化，并计算编辑距离。当前 accepted 门槛检查 raw CER，虽然计算 final CER，却没有将 final CER 纳入通过条件；保留为图像或遗漏区域仍依赖人工确认完整覆盖。脚本结果不能替代阅读顺序、版面和特殊字符类别覆盖检查。

本次新写的 `../.build/book-conversion-check/render-regression.swift` 仅包含四个合成几何场景，没有 OCR 调用；撰写本文时尚未编译或执行。它不属于已通过验证，真实书页修复结果和新的整本性能结果也不在本审查结论内。

### 质量结论及其边界

[最终文字层核验](validation-0.2.0/whole-book-text-layer.json) 中 `characterMismatches=[]`、`missingGlyphPages=[]`。前者只是导出文字与现有 OCR 文本的字符频次一致性检查，不能检出原 OCR 已有的错字和漏字；后者只是该检查未报告缺字页面，不能证明特殊字符识别正确。**这不是 OCR 正确率验收。**

`readingOrderDifferences` 实际包含 77 页，页序为：

8–10、16、19–21、30、37、39–41、45、49–50、57、59、61、63、65–67、69、71、73、78–109、112–113、115–130、136、145。

这些是原 PDF 页序，不是印刷页码；字符频次相同仍可能存在复制顺序、段落顺序等差异。全部 155 页均未完成人工校对，第 155 页没有可用文字层。逐页清单见 [需要核对的页面](../output/整本转换_20261106/需要核对的页面.txt)。

源页 1、6、20、40、155 与导出页在相同测试分辨率下渲染，像素差异均为 0；输出 PDF 搜索 `morphologically` 成功。[视觉与搜索记录](validation-0.2.0/pdf-visual-parity.json)仅覆盖这些抽样页，不是全书逐像素验收。

原书第 6 页一个对照扫描转写的段落含 440 个非空白字符；仅做 NFC 与去空白归一化后，旧图像与修复图像 OCR 的编辑距离为 23 → 0，CER 为 23/440 → 0/440。[单段记录](validation-0.2.0/paragraph-cer.json)只支持该段的改善结论，不能外推整书准确率，独立整书金标准仍未完成。

本轮没有新增付费云 API 验证。照片去弯曲、透视纠正、双页拆分、章节重排和 EPUB 尚未实现。最终可交付物是保留扫描页面、附带 OCR 文字的未校对初稿，以及继续核对所需的项目与质量记录。
