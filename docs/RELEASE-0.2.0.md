# 拾页 0.2.0 发布与验证记录

日期：2026-11-06

实测设备：MacBook Air，Apple M4，16 GB 内存，macOS 15.7.4。

本版修复 PDF 导入时“画布变大、书页内容仍缩在中央”的问题，新增整本本机 OCR 初稿与可搜索扫描 PDF 的直接转换流程。真实 155 页书籍已完成试转并生成可打开、可搜索的输出；**全书仍为未校对初稿，没有通过整本 OCR 准确率验收。**

## 本版变化与使用

- PDF 按显式 300 DPI 渲染，最长边限制为 4200 px，并保留 CropBox 与旋转方向。旧项目可“新建修复副本”，从保存的源文件重新导入，原项目与原识别成果保留。
- 页范围默认整本，也可先选前 3 页。“本机初稿”逐页识别和保存，支持取消后继续，并跳过已有结果。
- 可直接导出保留全部扫描页面的可搜索 PDF 与正文 TXT。需要精细重建版面时，仍可使用原页重建和逐页校对。

建议先打开本次输出，检查几个代表页的搜索、复制和阅读顺序，再决定哪些页面需要补识别或精细排版。完整操作见 [使用说明](使用说明.txt)。

### 文字层检查的含义

[最终文字层核验](validation-0.2.0/whole-book-text-layer.json) 中：

- `characterMismatches = []`：导出 PDF 中提取的文字与现有 OCR 文本的字符频次核验未发现差异。**这是导出文字保真检查，不是 OCR 正确率检查。**原识别中的错字、漏字仍可能原样进入 PDF。
- `missingGlyphPages = []`：该检查未报告缺字页面，不代表所有特殊字符都已识别正确。
- `readingOrderDifferences` 包含 77 页：文字提取顺序与现有 OCR 文本存在差异。字符频次相同不能证明词序、段落顺序或脚注位置正确，复制和二次利用前应核对。
- `unreviewedPages` 包含全部 155 页；第 155 页没有可用文字层，但保留扫描页面。

77 页完整清单已写入 [需要核对的页面](../output/整本转换_20261106/需要核对的页面.txt)，页码均指原 PDF 页序，不是书上的印刷页码。

### 单段 OCR 对照

原书第 6 页一个对照扫描转写的段落共 440 个非空白字符，仅进行 Unicode NFC 与去空白归一化。旧图像与修复图像的 OCR 编辑距离分别为 23 和 0，即 CER 从 23/440（约 5.23%）变为 0/440。见 [单段记录](validation-0.2.0/paragraph-cer.json)。

这支持“修复图像缩放改善该段识别”的结论；样本只有一个段落，不能据此宣称整书零错误、全书准确率 100%，也不能推断音标、罕见字或复杂版面都可靠。

## 保留的数据与当前限制

原 155 页项目仍保留此前的 3 页视觉 API 识别成果和 52 条操作记录；其中 49 条属于手工排版操作。新结果写入独立修复项目，旧成果没有被本轮试转替换。历史使用情况与证据边界见 [审查记录](BOOK-CONVERSION-AUDIT-20261106.md)。

本轮没有新增付费云 API 验证。手机照片的曲面展平、透视纠正、双页拆分、章节重排和 EPUB 导出尚未实现。复杂阅读顺序、音标、组合符号、生僻汉字等仍需人工核对；本版优先完成保留原貌、可搜索并可继续校对的整本初稿。App 使用本地临时签名，尚未通过 Apple 公证。
