拾页 0.4.0 · OCR Agent 与扫描书归档

推荐工作流
1. 打开旧项目时，若出现“旧版导入可能缩小了 PDF 内容”，点击“新建修复副本”。程序从保存的原文件重新导入；旧项目、原始转写和校对记录继续保留。
2. 可以选择文件，也可以直接从 Finder 拖入 PDF、图片；拖入单个拾页项目可打开继续。导入新书后默认选择整本。页范围菜单可以选择“整本”“前 3 页试识别”或“仅未生成转写的页面”，界面会显示实际处理页数。
3. 在“2 识别文字”选择本机初稿或 OCR Agent，并选择同时处理的页数（默认 2，可选 1–4）。点击开始后，多页独立处理，每完成一页就依次保存。本机初稿不需要 API，已有转写和手工区域会跳过。
4. 选择“开始 OCR Agent”时，确认发送范围、服务和当前 Skill。模型先读整页，本机 OCR 检查漏行和文字差异。有疑点时最多附局部图重读一次。
5. 有识别正文后，点击“3 导出可搜索 PDF”即可保存；“其他格式”提供 TXT 和原页重建：
   - 可搜索 PDF（保留扫描）：保留每一页的扫描外观，添加当前识别文字层，无需逐块调整字号。未识别页也保留并列入质量记录。
   - 正文 TXT：按项目页和来源页导出，方便检索、复制和进一步整理。
   - 可编辑 Markdown：输出正文、脚注和可编辑表格。在页概览核对并确认“跨页续段”后，导出时可连接相邻两页的段落。
   - 原页重建 PDF：使用已有区域和字体重排，适合逐页校对版式的资料。

查看进度与停止
- 左侧显示未识别、待核对、失败和已核对页数。点击状态卡片或筛选菜单只改变列表，不改变识别与导出范围。
- 处理时显示已处理页数和正在同时处理的页面；可以继续浏览，后台结果不会抢走当前阅读位置。
- 点击“停止处理”后不再安排新页；正在处理的本机页面可能需要等到返回。已保存页面保留，再次开始可继续。
- 失败页可以单独选择重试。本机初稿处理无文字的页。有旧转写需要重做时请选择 OCR Agent，并查看开始前的替换提示。
- 退出会先停止并等待保存，避免覆盖后台刚写入的进度。

校对与恢复
- 点击左侧页面，再点击原扫描上的区域即可编辑文字。字号、行距、边界和字体收在高级设置中，粗斜体、上下标和表格编辑仍可用。
- 点击“页面检查”中的问题可定位到原图。疑似漏行可用对应框添加文字区，再手工补录或复识别。每轮证据和模型回包可从“显示识别记录”找到。
- “下一待核对页”帮助连续校对；预览载入时会暂时禁用图上编辑。
- 原始转写与校对文字分别保存。手工编辑、换字体和重新排版不调用 OCR。
- 本机队列会跳过已有区域。需要重新识别已有页面时，使用 OCR Agent 或从原文件新建项目。
- 在“项目”菜单中可以打开项目、保存副本、显示所在位置或新建修复副本。
- 本机和 API 的完成页逐页保存。中断后重新打开项目继续；磁盘保存失败会停止新的本机队列并显示错误。

使用边界
- “识别完成”并不代表准确无误。需要核对音标、汉字、表格、目录和多栏阅读顺序。
- 可搜索 PDF 旁保存文字层核验记录。字符是否写入、复制顺序是否一致，与 OCR 是否忠于原书，是不同的检查。
- 本版修复 PDF 点尺寸到像素尺寸的缩放。旧项目应新建修复副本，不能把旧区域坐标直接套用在新图像上。
- 手机照片的透视、弯曲书脊、跨页拆分和反光，仍需先整理原图。照片按文件名自然排序导入，并处理 EXIF 方向。
- 当前输出 PDF、TXT 和 Markdown。以横排印刷页为主要适用范围，复杂版面仍需对照原图。

OCR Agent 设置
- 齿轮中填写接口基地址、视觉模型 ID 与密钥。可点“填入 OpenAI 示例”，或沿用支持图像输入的兼容接口。点“测试图片与结构”会发送随机测试图和当前 Skill。
- 默认内置书页 Skill。可导出模板修改，再用“导入 Skill…”加载 UTF-8 Markdown 文件。应用保存导入时的副本，编辑原文件后重新导入即可更新。
- 密钥使用拾页独立钥匙串；本机初稿不需要密钥。
