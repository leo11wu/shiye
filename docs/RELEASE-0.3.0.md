# 拾页 0.3.0 · 多页同时处理与使用体验

日期：2026-11-11。0.2.0 原始源码与安装包已保存为 GitHub 私有仓库的 [v0.2.0 基线](https://github.com/leo11wu/shiye/releases/tag/v0.2.0)。本版围绕“多页面同时处理”和“操作直观”改进。

## 使用变化

1. 按“导入文件 → 识别文字 → 导出结果”完成主流程。可以直接从 Finder 拖入 PDF、图片或单个项目包。默认使用本机初稿，可切换视觉 API。
2. 默认同时处理 2 页，可选择 1–4 页。每页独立识别，结果依次保存；完成数以保存成功为准。
3. 页范围可以快捷选择整本、当前页、前 3 页、未生成转写页或失败页。左侧状态筛选只改变显示列表，不改变识别和导出范围。
4. 处理中显示当前页码和进度，可以继续浏览，后台完成页不再改变当前阅读位置。
5. 停止后保留已保存页。重新打开后可续做；本机初稿跳过已有文字。失败页已有旧转写时，若要重新识别，可选视觉 API。
6. 高级排版和页面详情默认收起；可以跳到下一待核对页。预览载入期间禁用图上编辑，避免旧图与新区域混用。
7. 未识别、识别中和失败均有明确的下一步提示。无效页范围就地提示；有文字后顶栏直接提供“导出可搜索 PDF”。
8. 先显示窗口，再异步恢复上次项目；API 密钥在实际使用 API 时才读取，本机流程不需要等待钥匙串。

## 保存与取消

- 导入期间，界面翻页与保存快捷键不再把旧文档快照覆盖到后台导入进度。
- 退出先停止处理并等待当前任务收尾，然后保存；正在执行的本机 Vision 页面可能需要等待其返回。
- 单页识别问题保留失败状态并继续；服务鉴权、余额、持续限流等服务错误会停止后续调度。保存失败立即停止，不把未保存的结果计为完成。
- API 配置和页面使用开始时的快照，每个工作任务使用独立后端；每次新请求保留独立响应文件，重复来源页也不会覆盖另一请求的原始响应。重复来源并发缓存未命中仍可能产生重复请求，尚未实现进行中的请求去重。
- PDF 重建与 TXT 导出也支持停止，提交最终文件前再检查取消；界面仍先写临时文件，成功后替换目标。

## 本机多页实测

环境：macOS 15.7.4、10 个逻辑处理器、16 GiB 内存。输入为开发样本 PDF 的前 10 页；每种并发使用独立进程、独立未识别项目副本。时间包括本机 OCR 和逐页保存，不含导入、复制和导出。

| 同时页数 | 实际活跃峰值 | OCR 与保存耗时 | 成功 / 失败 | 进程峰值 RSS |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 1 | 4.281 秒 | 10 / 0 | 165.8 MiB |
| 2 | 2 | 2.707 秒 | 10 / 0 | 186.5 MiB |
| 4 | 4 | 2.897 秒 | 10 / 0 | 235.7 MiB |

三种并发设置的逐页文字校验值一致，源 PDF 校验值未改变。结果支持本版默认同时处理 2 页；增加到 4 页在该样本上没有继续变快。每种设置只运行一次，顺序固定为 1 → 2 → 4，可能受系统缓存和机器状态影响，不能推广为通用提速倍数。RSS 是基准进程峰值，不是系统或 GPU 的总内存。初轮系统服务访问受限导致的失败测量已排除。

可通过 `scripts/check_page_concurrency.swift` 复测。它只使用本机识别服务，所有输入只读，输出需指定新的目录。

## 用户指定文件的全页测试

另对用户指定的两份扫描 PDF 测试全部 25 页。每种设置使用新的项目副本，保持并发上限 4；均为本机 OCR 与逐页保存，不包含首次导入与导出时间。

| 输入 | 页数 | 同时 1 页 | 同时 2 页 | 同时 4 页 |
| --- | ---: | --- | --- | --- |
| 扫描样本 A | 20 | 7.13 秒 / 172.5 MiB | 5.97 秒 / 190.2 MiB | 5.55 秒 / 226.0 MiB |
| 扫描样本 B | 5 | 1.77 秒 / 151.1 MiB | 1.57 秒 / 176.5 MiB | 2.76 秒 / 223.5 MiB |

六次运行都完成全部页面，失败页为 0；实际同时活跃数分别达到 1、2、4。逐页文字校验值在三种设置间一致，源文件校验值未改变，保存后重读的识别页数完整。每种设置仍只运行一次，因此这是可复核的样本实测，不是通用速度承诺，也不是 OCR 正确率验收。

测试用 PDF、识别项目和输出文件保留在本机，不放入源码仓库。

## 使用边界

本版没有更换 OCR 引擎或解决全部阅读顺序问题。此前 155 页试转的 77 页提取顺序差异与整书未校对状态仍需按 [0.2.0 记录](RELEASE-0.2.0.md) 理解；本轮没有重新做整书准确率验收。照片曲面展平、双页拆分、章节重排和 EPUB 未实现。App 仍使用本地临时签名，未通过 Apple 公证。
