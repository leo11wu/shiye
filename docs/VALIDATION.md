# 拾页 0.1.1 验证记录

日期：2026-10-21（Asia/Taipei）。本机：Apple 芯片 arm64，macOS 15.7.4，Apple Swift 5.8.1 / Command Line Tools。

## 0.1.1 启动修复

用户报告 0.1.0 双击后立即退出。已读取本机崩溃报告并在正常启动中重现：`AppModel.init()` 把自身 Bundle ID 传给 `UserDefaults(suiteName:)`，macOS 返回空值，强制解包触发 `EXC_BREAKPOINT / SIGTRAP`。此前的 9 项界面检查使用 `--qa` 独立设置，未覆盖此路径；不能据其通过宣称 0.1.0 正常启动已验证。

0.1.1 正常启动使用 `UserDefaults.standard`；测试设置保持独立。新增 `scripts/check_launch.py` 对实际 App 连续启动两次，不传 `--qa`、`--ui-check`，检查主窗口就绪、进程持续运行和原错误不再出现。结果记录在 `normal-launch-checks.json`，独立解压检查记录在 `package-launch-checks.json`。

解压检查还发现临时目录项目的预览创建被路径检查误拒绝：Foundation 对已有 `/private/tmp` 目录和未创建的子路径采用了不同别名。项目现在先统一已有根目录，再校验子路径；保留越界与内部符号链接检查，并增加 `/tmp`、`/private/tmp` 下创建与重读预览文件的回归检查。

## 资源占用

- 随包字体 3,541,232 字节：Charis 7.000 的 Regular、Italic、Bold、BoldItalic，附 OFL。中文字体使用系统资源；资源来源与哈希见 `resources.json`。
- 不包含本机 OCR 权重、Python、Node 或浏览器运行时；应用没有主动下载模型或字体的代码。
- 本机六页扫描集导入测试的进程峰值常驻内存为 **43,974,656 字节（约 44.0 MB）**。
- 本机合成样张的界面、编辑及检查图生成过程中，App 进程峰值常驻内存为 **214,466,560 字节（约 214.5 MB）**。这包括检查图的额外开销，不代表空闲占用或整本书峰值。
- 安装包、App 和源码 ZIP 的实测字节数与 SHA256 单列在发行目录的 `manifest.json` 和 `SHA256SUMS.txt`；打包程序强制检查 ZIP ≤15 MB、App ≤30 MB。
- 0.1.1 App 文件总大小 **6,018,255 字节（6.02 MB）**，安装 ZIP **2,431,349 字节（2.43 MB）**。最终解压包的原生界面检查峰值为 **218,513,408 字节（约 218.5 MB）**；包含检查图开销。
